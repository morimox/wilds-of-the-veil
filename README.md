# 雾渡山河

雾遮旧路，落灯村只剩一盏渡灯。你从这里出发，用采回的药材和拾来的旧器换下一趟的盘缠。打不赢的仗可以先退，暂时看不懂的旧物值得收着。等你走得远了，从前经过的地方也许还会有新东西。

《雾渡山河》是原创单人文字仙侠生存冒险游戏。游戏从低阶散修的日常起步，围绕物资筹措、战斗取舍、修行突破和藏在途中细节里的路展开。内力、各类物品、术诀、配方、故事与界面均为本项目重新设计。

## 开始玩

用浏览器打开 [网页试玩](https://morimox.github.io/wilds-of-the-veil/?play=16)，即可从落灯村出发。

### 在本机运行

需要 Node.js 20 或更高版本。在项目目录运行以下命令，然后打开 [本地游戏](http://127.0.0.1:4173)。

```sh
node scripts/serve.mjs
```

测试版每次打开或刷新都会从落灯村重新开始。旅途中可以随时打开右上角的行旅菜单。运行以下命令可构建无需服务器的单文件版，用浏览器打开 `dist/雾渡山河.html` 即可游玩。

```sh
node scripts/build.mjs
```

GitHub Pages 的入口是同一份单文件构建。修改 `game.html`、源码或插画后，运行 `node scripts/build.mjs index.html` 更新线上入口。

## 行前须知

开场可以跳过。小面板先显示气血、饱腹和眼下的动作。气血与饱腹的说明可点开读。桌面右侧可以查看装备、物品件数和行囊余量。受伤、伤害、得物和线索等变化会在行动完成后短暂提示。

- 游戏时间会消耗饱腹。随时观察饱腹值，主动吃干粮或带来的料理。空腹时可以沿走过的路慢慢赶回已知据点。进入雾中的地点过多也会耗真气。
- 开局可以直接出门，也可以去坊市、进工坊或找药僮。途中先见到公开地标，熟悉的人、路上的痕迹和物证会带来新的去处。采过的资源、击败的猎物和带走的独件会改变现场留下的东西。
- 落灯村专营货摊有自己的货源和熟客往来。各州据点有本地产物和共用口粮。可出售的货在每处据点都能找到接手人。
- 雾梁、照原和鸣沙各有二十个地图点位。出门后打开山河图，可查看已听说的坐标以及自己走得通的道路。长途商路会消耗不少游戏时间。认下门可用钱跳到本州另一扇门，或从安全处用卷轴前往已认门。远程州阵可以分批修。
- 真气是使用术诀需要的内力。符法、内息、炼体、五行和神识各自由线索或师傅引出，可以带材料去当地学。右上角菜单可查看修习进度。城池、村庄和允许访客歇脚的宗门都能休整。
- 村里的仓库能存原料和装备。慢慢恢复药畦、备粮灶、锻炉和炼丹炉，放入原料后可以出门，等成熟或做完再回来取。家中生产会直接用行囊和仓库的料。
- 境界从炼气初期到金丹后期。三州都有常见猎物、强者、秘境和地方差事。白苇滩的护堤木台有河工护场，守尺观也办大比，台手收招后可以回去养伤。野外致命交手失利会伤身、失物并被送到据点。
- 认识丹师安蒲后可以买常用丹方。筑基丹和结丹散都有各自的线索和正炉工序。洞窟里找到的材料、旧账和回到现场做的验证各有作用。
- 兽肉要带回村做料理，兽革和妖目用于加工，妖丹可以换钱或炼丹。妖物守着的草药、矿石和旧物要等路让开后亲手取得，切磋奖品也找当事人领取。
- 点一次采一批，进度走完后留在现场。采到的材料和战后解取的部位留在各自的地点，右侧「脚边」可以按物品一键拾取，手头装不下的留在原处。
- 在不同地方找到的东西可以带到沙盘上对照。真正的水闸、秤梁和回声筒要亲手操作。浅处和深处的试错代价可以从本地的损坏和声音看出来。机关打开后，枝路和实物会留在当地。
