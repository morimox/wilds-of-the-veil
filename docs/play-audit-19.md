# 第二轮横向试玩二十问

这轮跑了旧版的路线和新增分支，优先检查一个选择会改变哪条路、养成要多付什么代价、做完事后当地会怎样。同类规则一起查。

| # | 玩到这里提出的问题 | 复现与处理 |
| --- | --- | --- |
| 1 | 第一次到叠石关，怎么已经知道对方要余节的货签？交材料又为什么少了 11 钱？ | 从照原办好货签进关，原先开口缺介绍，付款到结算才清楚。补验牌来由，同类现场花费从实际数据提前显示。 |
| 2 | 旧渡没复航，能不能绕过正渡先去照原？走了商船还能回头处理旧渡吗？ | 在外桩给夏狄四份松木、两份寒铁和七钱，凭商船货单先到照原。确认旧渡当时仍关着，之后返程才让它复航。货单只开商船水路，两条路的条件各自成立，保留。 |
| 3 | 泥蜕褂说能卸掉野兽力道，为什么挡水貂没生效？ | 穿褂同样出手与对照，确认没有计入野兽护持。把缺标的水貂、伏灰炭魈归回实际的兽类，两者重新参与同一套判定。 |
| 4 | 伏火坑的两处风孔说能压火，下一步怎么只有打怪？ | 逐个看过风孔，原先无法实际操作。现在能调整挡板，在帘外取少量暗金，内矿仍由守兽挡着。 |
| 5 | 沉水量站能在干台采晶，是否也能绕开水魁直接拿走水图？ | 实际在外围采到七枚晶屑，未开启水图。两个去处与看守关系成立，保留。 |
| 6 | 明明到了驿站还能耗掉真气，装备磨坏又得赶回落灯村。三州的据点能不能真正撑起远行？ | 避雾地标进出不耗真气。照原城蒲霖后炉和叩石院梁弦修具台可付费修装备，报价当面可查；途中用到的仓库和锻造仍要考虑行程。 |
| 7 | 平时为了肉、兽革和妖丹出门，有没有理由决定去哪、猎哪一种？ | 在白苇滩试过去只能在两种猎物间换。现在白耳兔可补肉，泥鳞兽出革较多。闸外浅阶、藻鳞泥浜和伏兔草丘各有四群，选择会改变所得和交手的风险。采空或猎空一处继续按自己的存量恢复。 |
| 8 | 炭篷驿遇到兽潮，战力不足时能保住牲口吗？晚到还有什么可做？ | 实走分水和转移牲口，栏杆完好，全程没开战。备料加固再击退豺也能保住围栏。等兽潮过去，坏栏杆仍可补修，修好后只结一次工钱。三条应对都成立，保留。 |
| 9 | 白蹄旧道用泥试石头，为什么伏潮息泥还在？ | 复做试验，确认这项是就物试一道泥痕，后续还需带着它查别处。保留实物，并让动作交代只试少许。 |
| 10 | 在白苇滩赢来的独件兵刃，下一场倒下后还能去哪找？ | 从新局按正常走法赢到渡口钩刃，再去碎石水眼打第二只泥鳞兽时倒下。旧规则让钩刃和革永远消失。现在它们带着倒下前的磨损留在现场，恢复后可折返取回。主动撤退时倒地也走同一规则。 |
| 11 | 晒盘坡只有一枚铜扣，先给药担点灯，以后还能修旧吊板吗？玩家下手前看得出要取舍吗？ | 手里只有松木时，原先只能看到低处修法，铆进去后再也拿不到第二枚铜扣。现在捡到铜扣就能看清两种修法和缺料，可以先点亮浅沟，也可以留扣备料，让两条路都开。两种修法分别复走。 |
| 12 | 系灯院做完差事，说第十二日再来，怎么第十一天夜里就能交？ | 在第 4.75 日完成，七日后到期是第 11.75 日。各宗门显示实际剩余时长。 |
| 13 | 用神识读狐狸的护势，怎么隔了一轮还有减伤？ | 对照有读招与无读招，下一记重击本应掉六点却只掉四点。护持只留在本回合，即使对手选择防守或疗伤也按时结束。 |
| 14 | 带伤学炼体后当前气血上涨，原来的伤是不是也治好了？ | 学前少八点，当前值和上限同加四点，缺口仍为八点。此处是提高体魄，保留。 |
| 15 | 打完一只矿傀就领暗星刀，之后玩家还有锻兵器的理由吗？ | 胜过一只就能打开甩到井外的柜子。柜里现在留断刀和锻图；暗星刀要在二级锻炉用暗金、寒铁、灵晶和松木锻出来。常用剑刀仍有便宜渠道。 |
| 16 | 打慢招守兽时，我为什么要放下弓来带盾？ | 包革小盾只在主动架住重招时卸力，双手弓弩和长兵要腾出副手。开战前后分别可选择架招、射击和换手，装备损坏时失去原有作用。 |
| 17 | 横生脉有两种妖兽，想采内层暗金，要不要把整片都清光？ | 打过铁斑蜥后，负砂豺的数量和守路状态未变。清走守在内脉的负砂豺、留下铁斑蜥，仍能采到暗金。按守物与位置决定打谁，保留。 |
| 18 | 荒地里准备不够时，是换一件装备继续往前，还是先折回去？ | 同样走鸣沙城到炭篷驿，横渊雨衣可省四点饱腹。回烟长杖能多撑两次积雾造成的耗气。采苇时穿水绡札甲的人少受三点擦伤。三件都要真的穿戴并保持完好。 |
| 19 | 天衡石台的持衡镜灵，会逼着炼气后期的玩家先吃掉唯一一枚筑基丹吗？ | 带备好的丹药和符进去，防重击、趁对手收势补给，拿到信物时仍是炼气后期，筑基丹也还在。另一趟先筑基同样能走通。两种准备都能过关，保留。 |
| 20 | 两趟远行中，为什么一直得跑回落灯村把猎物做成路粮？ | 计时发现赶路和整备约占三分之二的动作。给折水驿、炭篷驿加了两种各有实际材料和工钱的驿灶。可在当地处理这趟猎到的肉，再继续前往本州险地。 |

新增的夜班、宗门灯绳、旧闸悬赏和兽潮另走各条结果分支。大地图仍为原有 60 点。枝节的时长与主线估算见[游玩时间](play-time.md)。
