# 第 23 版横向复查

含猎场和世界路线剧透。这轮对照了三种不同的做法。《超苦逼冒险者》从当前仍在场的数量抽取对手，胜利才扣一只，开战耗当地时间而每回合没有等待。《小黑屋》的洞穴打通后能成为补给地，出门一趟里只补一次。用官方网页从准备好的近邻地图走到驿站，第一次进场补水和肉，离开再回就没有第二份。《破碎的像素地牢》让搜索耗时，窖库用短暂的声音提示让玩家推断看不见的巡逻，能遮挡视线的环境也给撤脱机会。 [原作战斗实现](https://html-classic.itch.zone/html/16142446/src/main.js) · [小黑屋官网](https://adarkroom.doublespeakgames.com/) · [小黑屋驿站源码](https://github.com/doublespeakgames/adarkroom/blob/main/script/world.js#L1007-L1033) · [窖库的开发演示](https://shattered-pixel.itch.io/shattered-pixel-dungeon/devlog/1629909/coming-soon-to-shattered-the-vault-quest) · [巡逻与追敌源码](https://github.com/00-Evan/shattered-pixel-dungeon/blob/master/core/src/main/java/com/shatteredpixel/shatteredpixeldungeon/actors/mobs/Mob.java#L1454-L1523)

## 二十问

| # | 出发前与实玩时的问题 | 判断 |
| --- | --- | --- |
| 1 | 重要材料多了以后，会不会只增加同类重复战？ | v22 两条同目标路线各需要 79 场、分别打 28 和 29 种对手，单一种至多 8 场，金丹中期到后期仍有 12–14 场。保留三档妖丹需求与三州补料来源。 |
| 2 | 是不是加长单场战斗才觉得有内容？ | 本轮猎场沿用原敌人的气血伤害和掉率。改动针对进哪条路、何时退出和打完能干什么。 |
| 3 | 混合猎场能不能靠连撤，遇到好的才打？ | 旧版从同一入口连续进退，老蜥可在第 38 次出现，撤了 37 次、零伤，整窝一只没少。短退后同一路保留对手，复测连进不再抽种。 |
| 4 | 退出几步后，先前打出的伤害去了哪里？ | 原先回场直接回满。现在短退保留伤势，脱离接触每经过一日恢复 6 点气血，三日后重寻。 |
| 5 | 撤退后想拿脚边已经解取的东西，还要不要重进？ | 水洞和石场都退回外沿。已落地的物品仍分种拾取，也能就地改走另一边。 |
| 6 | 自己打不过，是否得以受死才可离开？ | 普通撤退继续先算眼下追击，野外死亡保留当地对手与掉落。护场切磋走裁判收招的结算。 |
| 7 | 可以主动寻找强怪吗，是否能直接选首领？ | 两处现在可沿所见岩缝、擦痕找第二进路。内路偏向精英和首领，满群时仍常遇普通对手，逼近本身也更耗时。 |
| 8 | 换一边会不会凭空变出第二群，或同一个首领重复出？ | 实跑从内路打掉一只后，外路读到的是扣除后的同一群。另一边真打赢同种时更新旧踪。 |
| 9 | 风险是否能在决策前看懂，还是要靠读概率表？ | 木板、干石、北墙抓痕和更窄的回路在现场可见，情报由观察动作得到。精确权重保存在开发表。 |
| 10 | 据点快空时还在提示整片都满，有没有一致性？ | 观察文字根据在场、已清和修过后的状态变化。空场只有可办理的收尾，已耗尽的交手无法启动。 |
| 11 | 赢了就有稀有材料吗？ | 保留稳定可取的肉和革、概率取得的妖丹或妖目两种出物。拿不到稀珍时仍按实际脚边产出结算。 |
| 12 | 要带着什么在外头续打，带木头值不值？ | 两处各有看得见的灶或火盆。用一份松木能缓一部分血气，灰凉了才能再烧。普通营地资源和火位冷却有各自时钟。 |
| 13 | 一定要把整窝都清空才能歇吗？ | 外沿可退可歇，火位不要求清场。深处的旧车道和水槽确实经过群落，留兽则不能整修。 |
| 14 | 清完 39 只，之后回来还有什么可用？ | 搭回取水槽可替药棚恢复一畦灵草。该畦按独立存量回生，不产动物身体材料。 |
| 15 | 清完 81 只，拿完一次性奖就没有意义了吗？ | 支起旧车道以后横生脉和冷炉院实路双向开放，地图、行程和消耗使用同一条路的数据。 |
| 16 | 新的密径是否会抄近跨过旧门槛？ | 旧车道只连接鸣沙已有两地。实际在石场清完且撑梁才知道线路；跨州凭据与门阵规则各自成立。 |
| 17 | 长途出门为啥总在右边点饭？ | v22 复测正渡 1,637 次吃饭，229 段有连续重复。按库存、饱腹和先后状态逐段对照，175 段可用一次连吃代替，合计省 239 次点击。 |
| 18 | 伤、毒和真气不同，休息七次为什么要点七遍？ | 炭篷驿同样条件下，原先七次半日休息现在一次结清，共 3.5 日。衣药、伤毒、神识恢复与原逐次规则等价。 |
| 19 | 为省操作会不会自动吃贵药、清空背包或改变负伤代价？ | 连吃只扣玩家点开的同类食物，战中一次仍只吃一份。休息不代用药。按实测，满包时休息仍可恢复，粮食补助继续受容量限制。 |
| 20 | 磨损和修理是不是也该批处理？ | 两条 v22 完成线修理只有 10／9 次，远少于补粮和休息。优先改会影响备战和每趟折返的问题。 |

## 本轮能改变的走法

- 药谷看见粗蒲根后可绕到深水一侧。满群时遇精英或首领的概率从约 17.95% 变为 30.43%，走进需要 0.375 日。水槽搭回后能采药。该畦初始有 3 份灵草，上限 6，每 5 日补 2。
- 石场扶低棱靠近内巢，精英或首领由 11.11% 变为 20%，走进需要 0.5 日。清场后用两根松木帮管料人撑起旧木梁，通冷炉院车道用 0.875 日。精确在场、时钟和掉落见数值表。
- 在水洞和石场，各自烧一份松木补 10／12 气血和 8 真气。都耗半日，首处停 2.25 日可再生火，末处为 2.5 日。折返和换路照实际时钟改变一趟的花费。 [进路与种群](tables/mixed-hunts.csv) · [用时与耗材](tables/event-choices.csv)

正渡路线沿用第 22 版走法到金丹后期、六机关与三州阵。把真实操作逐项重放，在等价处实际执行 175 次连吃和 40 次连续歇息。总操作从 7,930 降到 7,574，其中吃饭少 239 次，休息少 117 次。通关目标、战斗、耗材、持有物和游戏时钟一致。这是指定走法中的节省量，初见阅读与各人备战习惯另算。
