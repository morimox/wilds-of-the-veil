# 第 21 版战斗、远行与报酬复查

本文含支线剧透。第 20 版两条从新局走到金丹后期、六处机关与三座州阵的路线，分别发生 35 场／120 回合和 36 场／140 回合。算上开战按钮，战斗只占成功操作约 2.2%–2.4%。两路各有约 21 场是补相同材料的战斗。正渡先行的一路卖货收了 3,857 枚灵钱，其中 3,780 来自寒铁；这个比例受测试路线默认采铁筹款影响。两条是按所选路线计的操作，读招、思考和初次找路的时间另算。

## 原作的三个地点

| 地点 | 实现 |
| --- | --- |
| 食人氏族与法师公会 | 两个营地初始各有三档对手，配置为 100、5、1。中立时可先去看营地、听双方招募。加入一方后得该方的本领和一批军需，另一方成为敌营。要动敌营的物资，先要清掉当地尚在的敌手。营地人数与任务数是不同的状态。 |
| 两营的战功 | 初步委托分别需要 2、10、20 份战功凭据，酬劳有兵器、衣甲或头具，也有 2、4、8 金币。之后还能交 20 份换 20 金币。所以开战的理由会从新装备变成继续筹钱或清营取用。 |
| 地下通道 | 银溪镇村长遇袭后能去贼窝，调查、交手和把一份线索给赏金猎人引出通道。三档敌人每次给 1、2、3 份线索，各钥匙掉率为 10%、50%、100%。逐段交 3、6、9 份线索，露出两道机关和最后的宝箱，各要相应钥匙。开完最后的箱子，银溪镇出现黄金和宝石，地精村出现木雕和铁像。三档对手初见就能出现在同一地点，种群与开机关的状态各自记录。 |

## 二十个自查问题

| 问了什么 | 怎么核对和改 |
| --- | --- |
| 1. 以前很少交手是每场太短，还是能去打的事太少？ | 计算两条完成线场数与回合。把新增投入放在会影响护送、开路和领钱的场合，沿用原回合速度。 |
| 2. 老要卖寒铁，在哪里能靠交手挣下一趟钱？ | 沉钟岭救人即有现金，照原两段按验货、试水结账，鸣沙的外线以后仍可接。数字对照见下表。 |
| 3. 新手什么时候能碰见一段有意义的短仗？ | 从新局走到车牌棚，赢两场救下脚夫，有人接手照料，当场有理由回棚。 |
| 4. 救过人还想找粮，有没有新风险和实物？ | 按脚夫的钥匙去晒盘坡，清两处看守，找货账，再去闭潮渡看第一批粮卸船。 |
| 5. 战败会不会把已经做的救人和开门抹掉？ | 败退仍保留已办妥的事。验证返回原地，没赢过的一员依旧在场。 |
| 6. 城里两份委托会不会只是同一批怪换名？ | 护货对人并回收实际货批，保闸对精怪并修复磨台。准备、目标和回礼都不同。 |
| 7. 为什么只能接一边，影响原门派吗？ | 两人同一趟排船，另一边另请帮手。散修、各门弟子均可接。拒绝另一份差事时能看到缘由。 |
| 8. 护货真有押物，拿双份钱怎么办？ | 绳钩由卸货人收回，货条带回才能退押。以同一份货条试第二次结账会拒绝。 |
| 9. 闸工为什么要等，战胜就能通水吗？ | 扶梯清两处水口，打退活石后，还得有一块寒铁把歪支脚卡回槽里。少拿寒铁时仍可折返送来。 |
| 10. 接了长差事有没有小结算？ | 照原两边都在四场后带回单子结一笔，后半段是可以停下来再办的独立工作。 |
| 11. 为了鸣沙的账一定得把三条外线全清吗？ | 任一出钱人都见过红绳，打一条并结账就能找隐藏卸货路。其余外线是独立工作。 |
| 12. 鸣沙两道仓门有没有固定的先后作答？ | 从任一门下手，剩下的人仍会拦路。两个入口都腾开，仓内首领才出现。 |
| 13. 巡路的谁会回来，首领会复生吗？ | 三条外线各一人按 7、8、10 游戏日轮换。卸货窑和空仓内的人打散后不回来。 |
| 14. 赢过两班只领一份工钱，会吞掉第二份吗？ | 同一地点的实胜逐场记账。两场都赢以后再办，每次应领一份，领齐后关闭。 |
| 15. 战前吃药和读招到底有没有用？ | 背崖灰衣会回血。炼气后期带回气药的一路，首领 11 回合；缺回气药的完整一路拖到 19 回合，血余 5 点。保留准备、破招与药物的差异。 |
| 16. 普通过路的人会踩中开幕即致命的首领吗？ | 大多数深处要先获得当地实物并开启上段动作。体验过外场才看得到里面，路也能沿原处退回。 |
| 17. 旧路明明可以交料，刚答应护栈就把旧路锁了吗？ | 问过背绳的人以后依旧可交兽革、灵草。两条途径都能得到同一个绳结，第二条只结自己实做的差事。 |
| 18. 走雪关途中补给没了，有没有来之前就能知道的办法？ | 护栈棚能烧带来的干枝暖身，背绳人交代还有三包备用粮，可按原价取一次。 |
| 19. 满包会不会把辨路或领钱的关键物件卡掉？ | 货账、印和回条用单独的关键物件格。沉钟岭给的车铃满包时留下可取，进度不倒退。 |
| 20. 养成时打过同境强敌，能否少做一部分静坐？ | 首次战胜一类同境或更高对手多得 2 点当前历练。重复打弱敌、反复切磋仍按普通历练，境界物资保留。 |

## 什么改变正常路线的战斗量

1. **同一个进度目标里有实际要解决的对手。** 闭潮渡离线试验保持同一通关策略和首领数值，只在旧闸深槽的两条落脚处各放一个看守。正渡到复航从 6 场／20 回合变成 8 场／35 回合，走到金丹后期、六机关和三州阵从 35 场／120 回合变成 37 场／138 回合。其中首领由 4 回合拉长到 14 回合，主要因为前两战耗尽了真气。先走商船的对照也试了两个前哨和中途回气；相同完成目标由 36 场／140 回合变成 38 场／147 回合。分段守关可以增加实战场次，中间的退路与补给能控制打到后面没真气只能硬磨的情况。试验未合入试玩。
2. **玩家日常缺的东西，打赢后要有合算的来源。** 同一炼气中期角色从落灯村出发，筹到 70 灵钱再回村恢复气血与真气。采铁用 27 次输入、4 份干粮、全程无伤。打五只持锤矿煞卖妖丹用 76 次输入、12 份干粮，累计受伤 80 点。按补回口粮和磨损估价，采铁留约 57 灵钱，打猎留约 28 灵钱。比较收益时要算赶路、用药、粮食、修具、当地能连打几场，以及能否同趟拿到其他急用物资。单有掉落和悬赏都是选项。
3. **需求要在阶段中反复出现，且能让玩家挑对手。** 正渡对照里，八次突破之前累计记录到 699 点历练，其中 642 点来自采集。金丹中期升后期这段直接交用了早先囤好的妖丹，期间的历练全由采集完成，实际交手 0 场。现有首胜历练奖励不足以改变此走法。同一种掉落能从几种对手取得，还能花在反复使用的装备修整、养成或战斗补给上，才有多次出门的理由。原作灵魂同时耗于不同兵器和法器耐久升级。《小黑屋》则让打下铁矿后活着回村成为长期生产的入口。 [原作配方](https://html-classic.itch.zone/html/16142446/src/data_studio.js) · [《小黑屋》铁矿事件](https://github.com/doublespeakgames/adarkroom/blob/main/script/events/setpieces.js#L3457-L3522)

同样在沉钟岭试了两种矿壁。加大原主矿壁的库存，还是得迎着回补打四个矿煞，耗 47 次输入，现金净收益约 15。单独用一个矿煞看一段矿壁，库存 8 寒铁和 4 灵晶，分两批撬取，矿煞七日后才回。这一趟打 1 场、4 回合，花 24 次输入、8.25 游戏日。按同一笔 70 灵钱并摊还耗材，净留约 60。安全采铁同样目标用 27 次输入、10.25 游戏日，净留约 57。两法的起点、商价和出门装备相同。矿物要在现场采下，耗材成本按补买价格和磨损折算。此条件下出现了合算的战斗走法，玩家长期是否采用还要看回补、其他猎场与装备。矿壁试验未合入试玩。

验收用同一终点下的净增胜场、对手分布、消耗和出行次数。新增地点里能点几次交手、首领独自多拖几回合，需要分别记录。
