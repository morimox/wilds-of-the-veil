# 道路、拦路者与脱身

山河总图显示三州。州图显示已知大地点、两端都已知的州内道路和通往已解锁邻州的路口。可把已知道路标红绕开，标红后按剩余道路重新求最短路。若会切断已知地点之间的连通，则不可标红。已标红的路可以恢复。

每个完整路格为二里、四分之一日，两端走向共用一段路。碰到拦路人或路边财物时停在实际走到的位置。处理完可以继续或沿刚走过的路折返。落灯村、有人巡守的城镇及宗门周边有安全道路。相邻两州之间较短的直连边固定安全，也不能标红。去渡口或驿关前经过的险路各自结算。渡船与传送不遇劫。[逐段里程与概率](tables/roads.csv)

## 普通拦路

- 路格先抽是否遇匪。命中再看外露装备和当地名册，盔甲权重最高，兵刃、帽、鞋也计入。各候选档都有活人时，炼气、筑基、金丹行头分别有 95%、92%、94% 抽到同档，其余只偏邻档。空档移除后按还在的档位权重抽。各相容档都空了就继续走。行囊里的备用物和角色真实境界不参与。
- 炼气强盗开价 2 至 8 灵钱，筑基开价 9 至 15，金丹开价 16 至 24。同一个活着的人报价固定。混付时先挑钱物，按买价与卖价的平均值取整，有货无买价则用收购价。确认后一次交清，当即放行并保留穿戴。凑不够还能交出随身装备、散钱和可抵价的财物求放行。信物、功谱和救济干粮随身留着。
- 拒付才交手。普通强盗败死，剧情人物按现场选择处理。胜后可得灵钱和对方用过的装备。同一个人手中的物件在本局固定。普通成员有 24% 机会留下可缴装备，偶尔富裕的成员为 75%。具体钱数、好货权重和不同境界的敌人另列。[强盗钱财及装备池](tables/bandit-pools.csv)
- 玩家战败时，普通强盗的杀人概率从 16% 起，每高一小境增加 2 个百分点，最高 32%。三处首领都是 30%。被杀后结束当局。其余情况会被搜走装备与灵钱，然后被扶回先前的据点。后来打赢当事人可找回财物，藏身处的失物可在那里取回。
- 空着两手、身上也没有穿戴装备时，有 65% 机会被普通强盗嘲笑一句就放过去。已经走了多远、手上有多少钱都不会改变他的开价。
- 打赢后留在路边。能落下的装备各自点取，可以用药，或从行囊换上别的行装，再决定继续还是折返。有话要说的剧情人物会留在现场，由玩家处置。下一场一开始，穿戴就锁定。

## 片区和山寨

60 个大地点连起 113 条路，37 条有路匪，分属九伙。每伙在自己的几条路上共用名册，同一个人一趟至多遇一次。进入一段路时，以基础概率乘该伙剩余人数比例、留守者影响和闪避减免，得到这段路的每格概率。装备闪避值合计乘 1.25，最高减 45%。这一段路的完整路格独立用这个概率，走了不足一格用 `1−(1−p)^长度` 折算。十个完整路格的命中次数服从 `B(10,p)`，不同路段各用自己的 `p`。同段路已遇过几人不会改变下格抽签。可用名册耗尽或服饰对不上当地团伙时，命中也可能没人拦路。[团伙人数、藏身处和管辖道路](tables/bandit-crews.csv)

固定每格 4.3% 连走十格，用 10,000 个种子检验。遇零、一、两次的实测为 64.52%、28.72%、6.02%，二项分布对应 64.43%、28.95%、5.85%。另选取每条路线 2,500 趟实际走完的记录，按沿途相容的行头取样，关闭特殊路遇剧情，以交钱通过保留本地名册。

一般的路匪空出一缺，先等 18 游戏日，然后每 6 日补一人。孤僻的团伙更难招人，实际日程见表。三处能攻进去的藏身处，首领一败就清除对应团伙的路上拦截。在寨里还可以与普通守卫交手，也能找回该伙留着的失物。

灰沟坡寨有 23 人。寨里每次按现存人数抽签，初战碰见许涧的概率是 1/23。三班普通守卫分别按 28、32、36 游戏日的班期补人，许涧只出现一次。许涧一败，巡山人便搭板通往后柜，可以清点 180 灵钱、他的宽背刀和余货。前棚里的人还可以照常交手。

到照原可以和收晒网的船家说话，到鸣沙可以问桥边盐车的事。这两路也能从拦路场景得到藏身处线索。寨内按实际留守人数逐个抽签，三处都能首战遇上首领。

白苇滩北堤有个歇车的挑夫，会随口讲这条道的行头与盘缠。灰沟几条路合计第三次遇匪时，若玩家还没解决灰褂人的事，那次必碰见他。对方看到难惹的行头会先收刀。交过路钱可看见去向，帮他裹伤可得一册功法，打赢后也可以听完他的请求再作决定。听他指路或查看车上的实物都会给出可以去往的明确地点。[固定人物与各分支](tables/bandit-stories.csv)

照原的「借粮」从白鹤粮仓到碎琉璃滩的路上开始。苏苇从仓里挪出了三家的种粮。封口、木签、经手人的证词和两张背面同号的账单各有用处。玩家可以私下归粮，保住经手人的身份；也可以找齐原单，当众撤掉冒卖的字据。两条路都归还种粮，当场选择决定地方留下什么变化。

## 试玩时追问的几个问题

| 问题 | 实际检查 |
| --- | --- |
| 首战便抽到许涧，打赢之后还要不要把剩下的人打完？ | 直接开放背坡货柜，前棚 22 人照样在。 |
| 背包挤满，专属刀和粮路的线索怎么办？ | 独件留在拿得到的现场；关键证据仍可随身带走。 |
| 首领落败后藏身处补了人，路上会不会重新拦截？ | 普通守卫恢复。该伙在路上的概率继续是零。 |
| 凑路费时改主意，或确认交付后是否还要打？ | 挑钱物只是估价，确认才一起交出。交清当即放行。 |
| 输给强盗后，能否空手重整，哪里找回装备？ | 放过的分支还有口粮和信物。打赢当事人能找回财物，原耐久随实物保留。 |
| 多带的内功会不会永久占着背包？ | 功谱可入仓。当前功谱入仓就停止运转，取出仍记得练到第几重。 |

## 州界与深入

炼气后期的行装在照原已有可做的事。闭潮渡外桩的小船靠修船料和船费开行，进入照原城后可去青埂打灵鸭，也能继续探测水尺、找沉水量站或通向错水湖底的旧路。

筑基初期可以经叠石驿关到鸣沙。拿杨木水栈的货签，补好关上的绳架便可过关。炭篷驿能歇脚，附近能猎到野兔与盐尾狐。要深入静盐井、架风板上旧弦库和琉脊天室，得另外找实物、过机关或迎战守物的强敌。回到雾梁也还有从白苇滩能望见、要晚些再探的回潮母洞一类险处。

## 脱身

撤退用掉一个出手机会。对手实际进攻时会追上来，来招照常结算。碰到守势、蓄势、闪身或调息时，才按敌人本身的基础概率抽签。闪避值的 75% 加入脱身值，再计装备、内功或符箓；一般对手最高 85%，强盗最高 40%。敌人没露招时，界面只显示撤退。场地有保护的切磋可以认输。[逐个对手的基础脱身概率](tables/enemies.csv)
