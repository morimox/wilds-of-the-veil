# 首轮体验与路图

开局验收的重点是玩家可以自由选方向，并在第一次主动用到一个数值时理解它。吃粮、出门、采集、狩猎、进村说话都可独立发生。

## 原作对照

- 作者发行的 v0.32 开局给基础工具和少量食水。生命、满腹等数值直接显示，悬停才展开简短的因果说明。食物词条显示能恢复什么，实际食用才扣背包数量。这给《雾渡山河》的启发是把说明放在数值及其对应动作上。 [作者发布页](https://maougame.itch.io/kubition) · [游戏界面与道具逻辑](https://html-classic.itch.zone/html/16142446/src/main.js)
- 原作的早期采集、人际交换和狩猎有各自入口。森林可先取眼前的物资，再通过人物的实际食物需求了解更远的路。猎物的背景说明也有具体人物入口。部分玩家攻略专门补充了如何给食和开图，说明有据可循的提示仍然有价值。 [地点配置](https://html-classic.itch.zone/html/16142446/src/data_place.js) · [同期玩家说明](https://www.ptt.cc/bbs/Little-Games/M.1449521751.A.46E.html) · [实况中的人物交物](https://www.bilibili.com/video/BV1Zb411r7jS/?t=63)

## 玩家第一次知道什么

| 碰到的事 | 眼前的动作 | 玩家由结果理解的规则 |
| --- | --- | --- |
| 落灯村能去滩上、找药僮、进工坊或逛坊市 | 先走到自己想去的地方，饿了再吃 | 饱腹变高，干粮少一份。路上的时间会降低饱腹。 |
| 滩上看得见浅苇、木桩、水眼和矮堤 | 自选去处，采、捞、绕、战或折返 | 看得见的地点一直可走。地点存量和背包件数随动作变化。 |
| 药僮刮着药罐，白苇芯已经见底 | 有苇芯时递给他，也可以等以后再来 | 他收的是手里实际带来的东西，交付后给一包松脂膏。 |
| 工匠看到玩家手里的泥蜕 | 听工匠说它适合做什么，收够材料可请他制备 | 打猎得来的东西遇到懂行的人才知道具体用途。 |
| 走进深苇或与猎物交手 | 观察、迎战或退走 | 气血损失当场明示。受伤后可以敷药或回村歇息。 |
| 开始学术或深入雾地 | 看真气、试施术、在合适的时候返村 | 真气会随施术下降。雾压在开始影响行动时才进入视野。休整和药物能改变状态。 |

说明可以随时在对应状态处点开。动作反馈记录当场的伤害、恢复、所得和发现。开发表保留精确战斗和道具参数，材料做法由人物与实物的往来带出来。

## 地点从哪出现

- 每个地区的公开地标在抵达时一起出现。进入或离开普通场景不会改变地图。随时间变化的是库存、动物活动和已发生的现场情况。
- 隐蔽的去处有具体来历。沿桩边的岸路辨认渡工的位置，或由矮石堤上的人指路，才知道刨木滩藏在哪一弯。背雨石渠需要实地去追水眼旁的水迹，沉桅高埂从渡工的旧桨辨出走法。
- 选项执行后的文字写清当时看到的路或听到的话。返回地区面板时可以直接去已经找到的地方，隔天或来回赶路也继续认得。
- 同一标准用在沉钟岭、闭潮渡和回灯埠。矿工留下的东西、运货人的话、旧闸旁的踏脚处都应先有所见，走近或动手之后才得知结果。验收要读初到、取走物件和耗尽资源后的同一个地点。

## 沙盘与现场

玩家先在不同地点找到各自成立的物件和话，再由自己写猜想。沙盘可以摊开所有随身物件，供玩家对照它们的原貌和出处。到了能动手的地方，试的是看得到的水、石、回声和旧器。错误的操作留下一次可观察的变化，成立时才给配方、新学会的本事或真正可走的路。

## 路图与实力

- 白苇滩之后的路由本人获得的路图打开。渡工能用一份真实的材料交换提供路图，击败带图的拦滩客也能取得。材料、战斗和地图物件是同一条因果链上的环节。
- 路图到手即可尝试通行，危险来自现场的敌人、补给与环境。境界继续影响自身能力和术诀、法器等条件。准备不足仍能观察、迂回或撤退。
- 留出过关以外的去处。打赢只结算该对手的物品，交付只结算该次交易，返回地点继续看到独件与种群已经发生的变化。

验收应从新局分别试一次先问药僮、直接去捞药篓、先狩猎再去工坊。核对未带对应材料时的人物反应，以及同一货源下坊市在采集前后给出的货单。第一次到滩、直接离开一个地标、折返和找到支路后的列表应与当前地形知识相符。渡工换图与直接在矮石堤过招都要能在原境界走进新图。后续主线、沙盘与回灯埠要有完整可走的路线。
