# 短期改造计划

本轮先把落灯村和白苇滩做成一个能反复往返的生存地点，再用同一套规则复核沉钟岭、闭潮渡和隐藏区域。验收标准是同一次游玩中，玩家能通过自己的行动改变一个地方，走开再回来时能认出这种改变。

## 对照原作

作者说明把饥饿、出门带补给、在家制作以及去更深处连成同一条生存循环。同期玩家记载还描述了在指定地方自主采集，给特定人物带东西以后开路，以及背包留空、当地产出和季节共同影响出门计划。本轮采用这些可核对的结构。个别版本的种群刷新公式未据此推定，本项目会单独定义时间与恢复量。 [作者发布页](https://maougame.itch.io/kubition) · [U77 发布页与早期玩家记录](https://www.u77game.net/yc/289.html) · [2015 年实玩记录](https://www.ptt.cc/bbs/Little-Games/M.1449521751.A.46E.html)

实操作者发布的 v0.32 时，森林单独给出砍树、采集、拾荒、狩猎和谈话。浆果采一次后，原地库存确实降低，拾起以后行囊才增加。狩猎前能看到物种活动的强弱。本项目将把可见状态和操作的距离作为验收点。继续使用自己的世界、地图布局、人物、掉落流转与恢复参数。 [v0.32 作者发行件](https://html-classic.itch.zone/html/16142446/index.html?v=1782553516)

## 第一阶段 · 让地点和时间持续存在

1. 进图后显示能从入口看见或已经知道的去处。选择地点进入相应现场，再决定采、找、捞、带回或与已经察觉的对手交战。藏起的去处应有明确入口和能被玩家指出的发现原因。
2. 同一处苇丛的浅挖和深挖消耗同一片资源。耗尽后会留下可观察的现场状态。资源只随游戏时间恢复到设定上限，折返、查看面板或重复打开地点本身不会补满。
3. 每个狩猎地点分别维护本地动物数量。击败才减员，撤退不扣，普通种群按自己的时间间隔逐批恢复。独件、唯一首领和完成的现场动作没有再生。
4. 地点状态和饱腹度共享游戏时钟。允许主动等候，等候消耗饱腹，也会推进地点恢复。测试页仍在刷新时新开一局，本局里的反复往返则持续使用同一份地点状态。

## 第二阶段 · 把药篓做成一件东西

1. 滩边只有一个药篓，拉回来后进入行囊。行囊满时留在脚边，整理之后可以拾回。回头再来能看见已经取走的现场。
2. 药篓可以查看线索并送回村。找到药僮后，完整交还会拿走实体并给出一次反馈和报酬。药僮之后想要的苇芯，与这次交还药篓分别成立。
3. 如选择拆篓取药，应明确这是取走内容的动作。消耗实体，无法再完整交还，得到的药物和材料有去向。单纯查看物件不消耗它。交付或拆过以后，原地点不会生成另一个。

## 第三阶段 · 统一生命、饮食和数量

1. 主面板显示实际气血与饱腹的当前值和上限，时间显示游戏日。需要进食时，饱腹旁就有吃干粮的入口。装备仍在右侧查看，行囊和脚边物品显示实际件数，词条及其用途继续按需查看。
2. 饱腹满值为 100。每游戏日消耗 16 点，吃一份干粮恢复 32 点。赶路和野外行动通过经过的时间消耗饱腹，实际干粮由玩家主动吃掉。饿尽会限制继续外探并影响交手，保留返村和救济路径。移动、等候、休息、制备和交战均走同一时钟。
3. 本阶段采用一条饱腹条。水在本版本用来形成地势、潮流和线索，水分机制留到存在有抉择的水源与补给路线时再评估。
4. 当前数值与变化反馈承担不同职责。气血、饱腹和物品件数用于做决策，受伤缘由、造成伤害、得物、交付和地点变化在行动后短暂提示。隐藏后果继续留在结算以后。

## 第四阶段 · 回归与发布

| 场景 | 验收 |
| --- | --- |
| 第一次出门 | 能直接挑公开地标，普通折返不会增加去处。藏起的路径只在玩家亲自找到入口、得到指路或读到路图后加入。 |
| 苇丛重复采集 | 同一片库存下降并可能耗尽。返回或重新打开仍旧耗尽，过了恢复间隔才重新提供产出。 |
| 反复狩猎 | 击败后当场少一只，撤退保持数量，时间推进后依上限补充。唯一敌人不会恢复。 |
| 药篓去向 | 拉回后有实物，查看仍可交还。装不下时可腾位拾取。交还和拆开两条路径互斥。 |
| 饱腹与数量 | 经时下降，进食同时更新饱腹及持有件数，空腹有实际限制也有返村办法。 |
| 既有内容 | 仍可两次突破并完成主线。沙盘能自由写猜想，现场可观察试错，再由实际结果解开隐藏区域或得到新本事。逐处确认描述和选择对应。 |
| 试玩发布 | 本地引擎回归、真实浏览器操作、单页离线包和公开入口均校验。同一份数值生成开发表格。 |

本阶段验收以动作是否改变世界和能否用观察做下一步决定为准。
